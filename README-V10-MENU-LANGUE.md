# KAWA BORA — V10

Cette version conserve le design V7 et les modifications du menu précédentes.

## Modification de cette version

Le changement de langue apparaît maintenant uniquement dans le menu principal.

Le sélecteur de langue qui pouvait apparaître ailleurs sur la page a été supprimé afin d'éviter la répétition inutile.

Langues prévues :
- FR — Français
- EN — English
- SW — Kiswahili

Aucun changement volontaire du hero, des couleurs, de la typographie ou de la mise en page V7.
